# linyan-dist

linyan Android release APK, `update.json` (public distribution), and the project showcase page.

- `update.json` — App 自更新契约；路径与字段保持稳定，勿改名或移动。
- Releases — 各 tag 的正式签名 APK。
- `index.html` — 非商业的个人作品说明页，经 GitHub Pages（main / root）发布。
- `assets/tip-qr.jpg` — 作者个人收款码，已从微信原图裁去外层绿底与宣传文字，并把残留的绿色标识改为朱印色；二维码本体、静区与「经营」字样未改动。

作品页为静态页（含一张本地收款码图），不依赖 CI，也不改动上述分发契约。
